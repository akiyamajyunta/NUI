# 09 エラー処理と権限

## 権限

| 権限 | 用途 | 拒否されたとき |
|---|---|---|
| カメラ | 撮影 | 説明画面を出し、設定アプリを開くボタンを表示。ギャラリー合成モードは使えることを案内。 |
| メディア保存 | 結果の保存 | 保存ボタンを押したときに要求。拒否されたら、キャッシュのファイルを共有（Share）で渡す代替を提示。 |
| 写真の読み取り | ギャラリー選択 | `expo-image-picker` の仕様に従う（システムピッカーで権限不要な場合あり）。 |

- 権限は、必要になったときに要求する（アプリ起動時に一括で求めない）。
- 「今後表示しない」で拒否された場合、アプリ内からは要求できない。設定アプリへの誘導を出す。

## エラーの分類と挙動

| 状況 | 挙動 |
|---|---|
| `supportsFocus` が false | 撮影画面に警告。撮影は可能だが、ピント指定が効かない旨を表示するか、撮影を無効にする（仕様は `DECISIONS.md` に記録）。 |
| `focus()` が失敗・タイムアウト | シーケンスを中断し、「ピント合わせに失敗しました」。再試行ボタン。タイムアウトは設定値（既定 1500ms）。 |
| `takePhoto` が失敗 | 中断。取得済みの1枚目は破棄。エラー内容をログ。 |
| 2枚の向き・サイズ不一致 | 合成を中断し、原因を表示。 |
| 位置合わせの信頼度が低い | 警告を表示して、オフセット0で続行（ユーザーは「位置合わせオフ」に切り替えられる）。 |
| SkSL コンパイル失敗 | 開発者向けにエラー全文をログ。ユーザーには「合成に失敗しました」。06の代替案へ。 |
| メモリ不足の疑い | 出力解像度を自動で一段下げて再試行（1回）。それでも失敗なら中断。 |
| 保存失敗 | 原因を表示し、共有への切り替えを提示。 |

## 共通方針

- 例外は握りつぶさない。`Error` に、原因と文脈（どの工程か）を付けて上位に伝える。
- ユーザー向けメッセージは日本語、平易に。ログは英語でよい。
- ログは `[tag]` 付きで `console.log/warn/error`（`tag` は `capture`、`fusion`、`align` など）。個人情報や画像データを出力しない。
- 非同期処理は、画面を離れたとき（アンマウント）にキャンセルまたは無視する。多重実行を防ぐ。
- アプリがバックグラウンドに行ったときは、カメラを非アクティブにする（`isActive` を連動）。
- 全体の ErrorBoundary を `_layout.tsx` に置く。
