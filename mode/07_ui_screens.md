# 07 画面仕様

UI文言は日本語。デザインは、ダークテーマ・シンプル・操作が確実であることを優先する。

## 共通

- 縦向き固定。セーフエリアを考慮する。
- タップ領域は 48dp 以上。
- 重い処理中は、操作を無効化して、進捗（段階名）を表示する。
- ライブラリのUI部品（ボタン等）は、React Native 標準の `Pressable` を基本とする（追加UIライブラリは入れない）。

## ホーム（`app/index.tsx`）

ボタンを縦に並べる：

1. 「撮影する」→ `capture`
2. 「ギャラリーの2枚から合成」→ `import`
3. 「擬似ペアでテスト」→ 元画像を1枚選んで NEAR/FAR 擬似ペアを生成して `result` へ（04参照）
4. 「ベンチマーク」→ `benchmark`
5. 端末情報（機種、Androidバージョン、選ばれたカメラデバイスの `supportsFocus` など）を、小さく表示。

## 撮影（`app/capture.tsx`）

### レイアウト
- 全画面のカメラプレビュー。
- 上部：戻るボタン、設定ボタン。
- プレビュー上に、2つのマーカー：
  - 被写体点：緑の円＋「ぬいぐるみ」ラベル
  - 背景点：青の円＋「背景」ラベル
- 下部：
  - モード切替（「ぬいぐるみ点を設定」「背景点を設定」）のセグメント。
  - シャッターボタン（大）。
  - 直近の撮影時間（例：`撮影 842ms`）と、ピント検証結果（OK/NG）の表示。

### 振る舞い
- 起動時、被写体点は画面中央、背景点は未設定。
- **背景点が未設定のとき、シャッターは無効**にし、「背景点をタップしてください」と案内する。
- プレビューをタップすると、現在のモードの点を設定し、**その点に `focus()` を実行**して、ピントが合うことを目で確認できるようにする。
- シャッター押下：
  1. 撮影シーケンス実行（03）。
  2. 実行中は「動かさないでください」を表示し、ボタン無効。
  3. 完了後、ピント検証（08）を実行し、結果を小さく表示。
  4. 自動的に `result` に遷移して合成を開始する（設定でオフにできる：撮影のみ繰り返す用）。
- 撮影後、被写体点に再フォーカス（裏で実行）。

### 設定シート
- 撮影戦略（S1/S2/S3）
- 写真解像度（選べるフォーマット候補）
- S3の追加待ち時間（0/50/100/200ms）
- シャッター音（オン/オフ）
- 1枚目の前に再フォーカス（オン/オフ）
- 撮影後に自動で合成へ進む（オン/オフ）
- 元画像を保存（オン/オフ）

## ギャラリー合成（`app/import.tsx`）

- 2つの枠：「近景画像（ぬいぐるみにピント）」「遠景画像（背景にピント）」。
- 各枠をタップして、`expo-image-picker` で画像を選択。サムネイルを表示。
- 2枚そろったら「合成する」が有効になる。
- 2枚の向き・サイズが違う場合は警告（サイズが違うときは、小さい方に合わせて縮小するか、エラーにするかを選択し、`DECISIONS.md` に記録）。

## 結果（`app/result.tsx`）

### レイアウト
- 上：結果表示キャンバス（Skia）。タップ・ピンチでの拡大は、可能なら実装（必須ではない）。
- 表示切替タブ（06のデバッグ表示）：結果／NEAR／FAR／マスク／鮮鋭度／オーバーレイ。
- 中：パラメータスライダー（閾値、マスクぼかし、NEAR寄り、境界収縮）と、スイッチ（位置合わせ、色合わせ）。変更時はプレビュー解像度で再合成する。
- 下：「保存」「撮り直す」「パラメータをリセット」。
- 計測表示：`読込 / 位置合わせ / 鮮鋭度 / ブレンド / エンコード / 合計` の各ms。
- 位置合わせのオフセット値と信頼度（低い場合は警告アイコン）。

### 振る舞い
- 遷移直後に、既定パラメータで合成を自動実行。
- 保存ボタン：出力解像度で合成→JPEGエンコード→ギャラリー保存。完了したらトースト（または簡易な通知）で知らせる。
- 失敗時は、原因と対処を表示する（09）。
