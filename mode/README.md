# AI実装指示書：ぬいぐるみ全面ピント合成カメラ（入口ファイル）

## 人間向け：使い方

1. このフォルダ `ai-prompts/` を、Expo プロジェクトのルート（または空のリポジトリ直下）に置く。
2. AI（Claude Code など）に、最初に次の文を渡す。

> `ai-prompts/README.md` を読み、そこに書かれた作業プロトコルに従って、`ai-prompts/` 内の全ファイルを番号順に読んでください。読み終えたら、実装計画を短く提示してから、`11_milestones.md` の M0 から順に実装を進めてください。

3. 各マイルストーン完了時に AI が報告するので、実機で確認して次へ進める。

---

## AI向け：作業プロトコル（必ず守る）

1. **全ファイルを番号順に読む。** 読み終えるまでコードを書かない。
2. **最初に実装計画を提示する。** 各マイルストーンで作るファイルと、確認方法を数行で示す。
3. **`11_milestones.md` の順序に従う。** 前のマイルストーンの受け入れ条件を満たしてから次へ進む。
4. **ライブラリのAPIを記憶で書かない。** インストール済みパッケージの型定義（`node_modules/<pkg>/`）、README、公式ドキュメントで確認してから使う。特に `react-native-vision-camera`、`@shopify/react-native-skia`、`expo-file-system`、`expo-media-library` は版によってAPIが大きく変わる。
5. **仕様とAPIが食い違ったら**、`docs/DECISIONS.md` に「何が食い違ったか／採用した代替案／理由」を記録して、代替案で進める。
6. **実機でしか確認できないことは完了扱いにしない。** 「ユーザーに確認してほしい手順」として報告に列挙する。
7. **質問は進行不能な場合のみ。** それ以外は仮定を置き、`docs/DECISIONS.md` に記録して進める。
8. **各マイルストーン完了時に必ず実行する:** `npx tsc --noEmit`、lint、単体テスト（あれば）。結果を報告に含める。
9. **スコープを広げない。** 各ファイルの「やらないこと」を守る。
10. **外部API・ネットワーク通信・クラウド推論を実装しない。** すべて端末内で完結させる。

## 「実行できる状態」の定義（最終ゴール）

`npx expo run:android` でビルドした Development Build が実機で起動し、次が一通り動くこと。

1. カメラ権限を許可できる。
2. プレビューが表示され、「ぬいぐるみ点」と「背景点」の2か所を指定できる。
3. シャッターボタンを1回押すと、2点にそれぞれピントを合わせた2枚が連続撮影される。
4. 2枚が自動で位置合わせ・合成され、結果が表示される。
5. 結果を端末のギャラリーに保存できる。
6. 撮影時間と合成時間が画面に表示される。
7. カメラを使わず、ギャラリーから2枚を選んで合成するモードがある（開発・検証用）。
